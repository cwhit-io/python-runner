Using API Tokens

To authenticate your API requests, include the token in the Authorization header:

Authorization: Bearer YOUR_TOKEN_HERE

Example with curl:

curl -H "Authorization: Bearer YOUR_TOKEN" http://localhost:8000/api/protected/items/my-items
