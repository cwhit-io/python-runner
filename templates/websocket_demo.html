WebSocket Integration

This page demonstrates real-time WebSocket communication:

  • Chat Room: Public chat that all connected users can see
  • Notifications: User-specific notifications (requires login)

Implementation Example:

// Connect to WebSocket
const ws = new WebSocket('ws://localhost:8000/ws/chat/lobby/');

// Handle incoming messages
ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log(data.message);
};

// Send a message
ws.send(JSON.stringify({message: 'Hello!'}));
